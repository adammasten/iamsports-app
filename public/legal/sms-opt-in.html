How you opt in to IamSports text alerts

Operated by I AM SPORTS LLC, Austin, Texas, USA · adam.admin@iamsports.com

IamSports sends team schedule alerts by SMS only to people who actively opt in inside the app. This page publicly documents that consent flow. Below is the exact opt-in screen users see (Account → Manage text alerts).

The opt-in screen (reproduced exactly)

Send my code

The consent checkbox is not pre-checked. The "Send my code" button stays disabled until the user actively checks the box.

How consent is captured

  • The user enters their own mobile number.
  • The user must actively check the consent box shown above — it is never pre-checked.
  • Only then does "Send my code" become active. The app then texts a one-time verification code, which the user enters back into the app to confirm the number. (This is a transactional opt-in step, not a program message.)
  • Only after the user enters that code back into the app is the number opted in. Consent is collected solely from the person who owns the number; it is never purchased, sold, or shared.

Messages this program sends

  • Schedule update: "IamSports: Warriors 14U — Saturday's game vs Rivals moved to 7:00 PM, Field 4. Reply STOP to opt out, HELP for help."
  • Game/practice canceled: "IamSports: Warriors 14U — tonight's practice is canceled. Reply STOP to opt out, HELP for help."
  • Snack reminder: "IamSports: You're on snacks for Saturday's game vs Rivals (10:00 AM). Msg & data rates may apply. Reply STOP to opt out, HELP for help."

Program details

  • Program: IamSports team schedule alerts.
  • Message types: game/practice added, moved, or canceled; occasional snack-duty reminders.
  • Frequency: varies, about 2–6 messages per family per month.
  • Cost: message and data rates may apply.
  • Opt out: reply STOP at any time. Help: reply HELP, or email adam.admin@iamsports.com.
  • No sharing: mobile information and messaging consent are not shared with third parties or affiliates for marketing or promotional purposes. See the Privacy Policy.
